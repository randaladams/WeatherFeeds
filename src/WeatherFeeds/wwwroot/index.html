History

Saved as one CSV file per weather station in %LOCALAPPDATA%\WeatherFeeds\history. NWS only keeps about 7 days, so longer trends build up while the app runs.
The browser preview keeps only the last 3 days. The Windows app saves readings as CSV files.

Alerts & sound

The sounds are made up in code and are deliberately not the EAS two-tone signal, so a speaker that leaks onto air won't cause an FCC problem.

NWS identification

NWS asks every app to include a contact email so they can reach you if there's a problem. Please enter one.
The Windows app sends this as the required User-Agent header:
✓ Sent with every request to NWS, including radar images. Changes apply right away.
Browsers don't let a web page set User-Agent, so this preview can't send it yet. The Windows app will send it with every request.
NWS is only testing API keys on some endpoints, and none of the feeds used here need one. If you enter one, it's sent as an API-Key header.
